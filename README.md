## 📌 About This Repository

This repository contains my notes, PDFs, SQL queries, practice exercises, and projects created while learning SQL step by step.

The learning path follows a long-form SQL course that covers:

- SQL fundamentals
- Database setup and querying
- Data definition and manipulation
- Filtering, joins, and set operators
- SQL functions and analytical functions
- Advanced SQL techniques
- Database performance and optimization
- Data warehouse development
- Exploratory and advanced data analysis

> **This is a living repository.** New notes, exercises, scripts, datasets, and projects will be added as I make progress through the course. The folder structure and README may change over time.

## 🧑‍💻 Practice Examples

### Select data

```sql
SELECT *
FROM employees;
```

### Filter and sort data

```sql
SELECT name, salary
FROM employees
WHERE salary > 50000
ORDER BY salary DESC;
```

### Group and aggregate data

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department;
```

### Join related tables

```sql
SELECT
    customers.customer_name,
    orders.order_date,
    orders.total_amount
FROM customers
INNER JOIN orders
    ON customers.customer_id = orders.customer_id;
```

## ✅ Suggested Learning Workflow

1. Watch one lesson from the course.
2. Read the related notes or PDF material.
3. Write the examples yourself instead of only copying them.
4. Practice with a small sample dataset.
5. Save useful queries in the `queries/` folder.
6. Add explanations and mistakes to your notes.
7. Mark a topic as complete only after practicing it.
8. Build projects to connect multiple SQL concepts together.
